本意为 3 个独立 OS-level Terminal 窗口 + 1 个 Chrome 窗口同框。实测在 macOS Sequoia 上： osascript 报告 3 个独立 Terminal window id 但视觉上被 "Merge All Windows" 合并到单 window 的多 tab； set bounds 调用对合并 tab 静默失败（return 报全屏 bounds 不变）。 未尝试更激进手段（关闭 Terminal "prefer tabs" preference + 重启 Terminal app）因为本 Claude Code 会话本身跑在 Terminal 里、重启会自杀。 最终交付：(a) dashboard 上方 3 个 tmux-styled 面板已内嵌 3 路真 claudefast 输出字节； (b) 原始 tmux capture-pane 字节单独作 .txt 提供，可 curl 字节级核对； (c) Chrome 真窗口由 ①②③ 三张 OS 级抓拍证明； (d) 此声明完整公开局限，符合 docs/VISUAL-PROOF-CONTENT.md §"诚实声明 ＞ 修饰" 精神。
