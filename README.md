# teambrain-proof

Visual proof of work artifacts for [TeamBrain](https://github.com/libz-renlab-ai/TeamBrain) PRs.

Per [`docs/VISUAL-PROOF-FORMAT.md` § Hosting](https://github.com/libz-renlab-ai/TeamBrain/blob/main/docs/VISUAL-PROOF-FORMAT.md) — this repo serves the self-hosted GitHub Pages fallback path. The canonical recommendation in the merged docs is still GitHub Gist + htmlpreview.github.io for zero-bootstrap PRs; this repo is used when a PR's HTML doesn't render cleanly through the htmlpreview proxy.

Artifacts live under `pr-<N>/<slug>-<ts>.html`.
